# Kickstart Consulting website

A simple one-page static website. No build step or dependencies.

## Files
- `index.html` – page content
- `style.css` – design and styling
- `script.js` – closes the mobile menu after a link is clicked

## Hosting
Upload all files to the root of any web host, or push to GitHub and enable
GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
Keep the files together in the same folder.
